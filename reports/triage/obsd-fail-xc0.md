1. Missing or hidden Base interfaces and constants (headers aio.h and wordexp.h, EMULTIHOP/ENOLINK/ESOCKTNOSUPPORT, SIGEV_*, SIGRTMIN, timers, pthread types in <signal.h>/<sys/types.h>, va_list, SEEK_*, Issue 8 additions winsize/tcgetwinsize): all SYSTEM; the tests are right.

3. Utility output formats that differ from the specified formats (ar -v lines, ar -tv, ctags -x, diff -u headers, alias diagnostics on stdout) and Issue 8 behaviours (cd '', cd dot-dot).
4. The slow guest: tests that spawn a process per iteration of a set-up loop pass the 60 s limit when printf is not built in; use shell built-ins (echo) for bulk set-up. Four fixed here; other modules may have the same pattern (grep for loops around printf).
5. An interactive shell started with stdin from a file hangs in the guest: ENV (six lines here, same as the other BSD's triage).
6. head -c (standard in this edition) is not supported by the system's head, which hides stderr in the many tests that show it with head -c; a portable way to show diagnostics (tr and cut) would make guest failures like the ex family diagnosable.
