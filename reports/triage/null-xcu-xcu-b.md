# Null-system triage: xcu-xcu-b

Reviewer notes. Control = real shell kept, stub utilities first on PATH. Fixed tests were re-run on the control (`ci/nullsys.sh run --real-sh /tmp/null3`, one assertion per run) and normally (`posixcheck.sh --only`). Lint is clean for the changed files. Nothing committed.
