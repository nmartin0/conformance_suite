## Patterns

1. A utility or option of Issue 8 the system lacks (read -d, trap -p, realpath -e/-E, sed s///i, case ;&, uudecode "-", ulimit -v, test/ps -G) or a base utility that is missing (newgrp, pathchk, tabs): 38 SYSTEM lines, same cause as the other BSD where it was triaged.
2. Terminal tests: a pseudo-terminal that is not the controlling terminal, and input typed before the program is ready. Both are harness faults (71 TEST-BUG lines, 57 of them vi).
3. `}` straight after a command in sed scripts: the page requires a newline or semicolon. Other sed tests may have the same habit (grep `[a-z]}` in `modules/xcu/sed/t`); only the four in this list were changed.
4. Exact output compared where the page leaves blanks open (od).
