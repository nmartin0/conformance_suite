## Summary

Counts: ENV 19, STD-AMBIG 22, SYSTEM 248, TEST-BUG 25, UNKNOWN 1.

Recurring patterns:

- SYSTEM (largest group): the system deviates from Issue 8 wording that is new or stricter than older releases: strftime/strptime flags and widths (the plus flag, %C padding, %V range, %Z and tm_isdst, ERANGE, tzset), strfmon plus flag, sysconf values (_SC_VERSION 200809, HOST_NAME_MAX 64, a name that fails EINVAL, ARG_MAX changing after setrlimit), thrd_sleep leaving errno unset, wcstok setting errno, ttyname_r/ERANGE, and regcomp subexpression and regoff_t rules.
- Many SYSTEM lines are errno-or-privilege rules for the ID-changing functions (setegid, seteuid, setregid), rename with dot or a trailing slash, select with regular files and FD_SETSIZE+1, sched_setscheduler's return value, and math/complex ulp and errno behaviour.
- TEST-BUG: (1) tests that blocked forever or gave a false UNRESOLVED because a pseudo-terminal holds the writer while output is suspended (tcflow, tcflush); (2) a race in the orphaned-process-group set-up (the grandchild read its parent's pid after the parent had already ended), which affected five terminal tests; (3) places that needed the exact error where XSH 2.3 lets any applicable error be returned (overflow tests for readv/writev/recvmsg/sendmsg accept EINVAL or EFAULT); (4) set-up helpers that depended on the property under test (getgrgid/getpwuid unused-ID search, fmtmsg label, getopt optind); (5) setlocale.007 depended on implementation-defined extra locale categories.
- STD-AMBIG: lines already disputed stay INSPECT; new Q rows: Q-200 (2.11 data types), Q-201 (fmemopen orientation), Q-205 (wordexp stored word count after failure).
- ENV: no controlling terminal, no tty, locale and message-catalog tools missing, devpts mode, and a pseudo-terminal that does not queue suspended output.
