# Blind review 1: i386 System V ABI batch (abi/sysv)

Reviewer procedure: own reading of the psABI source first (notes written before
abi/ was opened), then comparison, then adversarial run. Oracle: the i386 psABI
source `low-level-sys-info.tex` ("current"), with the older revision `abi386-4`
("older") for the points where they differ. Passages are quoted in short phrases
only. Runs: `sh abi/run.sh i386` (70 PASS, 2 UNTESTED before and after),
`sh abi/control.sh` (31 detected, 0 missed before and after), lint 0 problems
before and after. Also run for this review: `-O2`, `-no-pie`, `-static`,
`-static-pie`, `-fPIC -pie -Wl,-z,lazy`, `-mstackrealign`, clang 18 (all as the
base run, except clang: types.008 FAIL, already in known-deviations), and
non-conforming builds (`-mrtd`, `-mms-bitfields`, `-fpack-struct=2`,
`-fshort-enums`, `-funsigned-char`, `-m128bit-long-double`, `-fcall-used-esi/ebx/edi`,
`-mno-80387`, `-msoft-float`, `-mpreferred-stack-boundary=2`).

Kinds: ASK = asks more than the text; LESS = accepts less; SILENT = settles an
unclear or revision-dependent point silently; CLASS = class mis-stated or
inconsistent; REL = relies on compiler/libc behaviour the text does not give;
PROC = procedure (setup reported as a verdict, copying).

## Phase-2 disagreements settled in the builder's favour

- entry.007 masks RC and the six masks only; my first draft compared the word.
- entry.008 `disputed`: the older table gives PC=11 but labels it 53-bit and its caution says start-up changes it to 64 bits; the builder's reading (follow the current table, INSPECT on FAIL) is right.
- entry.002, calling.011/.012, threads.002, signals.001/.002 `disputed` on 16-byte alignment: right (older: word).
- entry.011, calling.008 `disputed`: the older text states empty stack; the current only "x87 mode".
- entry.009, calling.006/.007, threads.004-.007 `required` although only current: right, the older text predates MXCSR and says nothing on the control word.
- calling.014 "pops that argument": the current text makes the callee pop it, the older text agrees; right.
- calling.024 checks only the compiled caller against garbage upper bits: right ("must not rely").
- types.001 enum = int, types.002 long long align 4, types.004 double align 4, types.005 long double 12/4, types.006 complex sizes, types.009 `size_t`: all match the current table.
- types.013-.016 `disputed`: the layouts match the older figures (checked against Figures 3-9 to 3-13); the current text has no bit-field rules.
- signals.004-.007 `disputed`: the older sentence on registers restored; the current text has no section on signals; right.
- entry.012/.013 `untestable`: right.
- Wording: no test, assertion or note names a system or a library (grep clean); only control.sh comments name a compiler.
